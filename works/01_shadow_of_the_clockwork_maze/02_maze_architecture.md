# 02. 미궁 구조 설계서 (Labyrinth Architecture)

- **작성 에이전트**: 백시우 (미궁설계자)
- **미로 유형**: 3중 동심원 시계태엽 회전 미궁 (Concentric Clockwork Labyrinth)
- **중심 테마 질문**: "과거의 과오로부터 도망치기 위해 지은 미로에서, 우리는 과연 출구를 발견할 자격이 있는가?"

---

## 1. 미로 구조 청사진 (Labyrinth Topology)

```text
               [외부: 폭풍우의 절벽 / 절단된 도개교]
                                ▲
                                │ (유일한 출구 게이트)
    ┌───────────────────────────┴───────────────────────────┐
    │  Outer Ring (외부 고리 - 12개 섹터): 객실, 서재, 온실 │
    │    ┌─────────────────────────────────────────────┐    │
    │    │  Middle Ring (중간 고리 - 8개 섹터): 회랑,  │    │
    │    │  박물관, 거울의 방, 기계 환기구              │    │
    │    │    ┌───────────────────────────────────┐    │    │
    │    │    │  Inner Ring (내부 고리 - 4개 섹터)│    │    │
    │    │    │  ┌─────────────────────────────┐  │    │    │
    │    │    │  │  Centrum (중앙 심연):        │  │    │    │
    │    │    │  │  거대 괘종 메인스프링 제어탑 │  │    │    │
    │    │    │  └─────────────────────────────┘  │    │    │
    │    │    └───────────────────────────────────┘    │    │
    │    └─────────────────────────────────────────────┘    │
    └───────────────────────────────────────────────────────┘
```

- **진입점 (Entrance)**: 저택 1층 대현관 (자정이 되는 순간 육중한 놋쇠 격벽이 내려와 봉쇄).
- **중앙 심연 (The Heart/Centrum)**: 높이 15미터의 거대 시계 메커니즘 룸. 저택 전체를 회전시키는 메인 태엽과 유진우의 서재가 위치.
- **주요 분기점 (Key Junctions)**:
  - **분기 A (서재 ↔ 거울의 방)**: 00:15분에 문이 열리나, 진입 후 00:30분에 벽이 회전하여 막다른 독방으로 고립됨.
  - **분기 B (온실 ↔ 기계 환기구)**: 유황 냄새를 따라가면 지하 수력 파이프라인으로 연결되나, 00:45분에 수문이 개방되는 위험 구간.
- **막다른 길 (Dead Ends)**:
  - 막다른 길 1 (동쪽 전시실): 멈춰 선 태엽 인형들이 늘어선 방. 인형 손에 쥐어진 암호 쪽지 획득 가능.
  - 막다른 길 2 (남쪽 회중시계실): 40개의 시계가 일제히 울리며 청각적 패닉을 유발하는 함정 공간.
- **탈출구 (The True Exit)**:
  - 외부로 나가는 출구는 현관이 아니라, **Centrum의 메인 태엽을 역회전(Counter-Clockwise)시켜 지하 수로의 배수 게이트를 개방**하는 것.

## 2. 미로 작동 규칙 및 시간표 (Labyrinth Mechanics)
- **00:00 (자정)**: 현관 격벽 폐쇄, Outer Ring 회전 개시 (시계 방향 60도).
- **00:15 (1차 변형)**: Middle Ring 회전 (반시계 방향 45도), 서재와 복도 분단.
- **00:30 (2차 변형)**: Inner Ring 회전 (시계 방향 90도), Centrum 진입로 일시 개방.
- **00:45 (3차 변형)**: 전 고리 동시 연동, 저택 내부 기압 하강 및 배수관 침수 개시.
- **01:00 (최종 잠금)**: 모든 격벽 영구 봉쇄 (제어탑 정지 시 생존자 질식 위험).

- [x] 공간 구조가 주제 의식과 긴밀히 연동되어 있는가? (시간을 되돌리려는 인간의 집착을 공간화)
